# Survey of Data Sources

Map the landscape: documents, databases, APIs, and application-resident knowledge.

## Details

Characterize each source class: typical formats, access patterns, update cadence, implicit structure, and extraction pitfalls. Provide decision matrix for prioritizing sources by business value and feasibility.

### Outcomes
* Identify key format differences (PDF vs. DOCX vs. HTML vs. Markdown).
* Contrast relational vs. NoSQL extraction considerations.
* Understand API & application data access constraints (rate limits, auth, pagination).
* Build a source inventory & scoring rubric.
