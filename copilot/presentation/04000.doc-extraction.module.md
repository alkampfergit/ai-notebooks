# Document Extraction Techniques

From raw files to structured, metadata-rich text units.

## Details

Deep dive into parsing strategies for PDFs, DOCX, HTML, Markdown. Cover OCR for scanned content, table extraction, image alt-text enrichment, layout segmentation (hierarchy, headers, lists, callouts). Emphasize preserving structure & semantics (headings, numbering, captions) and harmonizing metadata across heterogeneous formats.

### Outcomes
* Select appropriate libraries & pipelines per format.
* Extract hierarchical structure & semantic blocks.
* Handle tables, images, code blocks, footnotes.
* Normalize and enrich metadata (source, page, section, layout role).
