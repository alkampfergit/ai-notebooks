# Metadata-Enriched Chunks

- Add structured metadata (titles, section, author, date, tags) to chunks to enable hybrid retrieval filters.

## Details

Topics:
- Choosing metadata fields and schemas for common corpora (docs, web, code, tables).
- Combining metadata filtering with semantic ranking (e.g., pre-filter by date or section).
- Provenance and traceability: storing origin, offsets, and retrieval signals.
- Index cost and design considerations when storing many metadata fields.

Exercise: design a metadata schema for a knowledge base of product docs and show example queries that benefit from metadata filters.
