# The 6 Core Stages

1. Author / Source Creation
2. Extraction (Acquire, parse, enrich)
3. Indexing (persist chunks + metadata)
4. Retrieval (candidate selection & rerank)
5. Augmented Generation (LLM w/ context)
6. Post‑Processing & Feedback

## Details
Briefly define each stage using verbs to emphasize responsibility. Highlight boundaries: Extraction ends when normalized, enriched chunks + metadata are ready for indexing. Post‑processing is where evaluation, guardrails, and signal capture happen. Encourage participants to sketch this now; they will refine later.
