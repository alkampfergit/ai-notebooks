# Structure-Aware Chunking (Headings / Layout / Tables)

- Use document structure to create semantically meaningful chunks.

## Details

Explain how to use headings, DOM structure, table schemas, and other explicit markers to guide chunk boundaries.

Topics:
- Heading-based segmentation and hierarchical chunks.
- Preserving table integrity: when to chunk rows vs. entire tables.
- HTML/DOM-aware chunking for web pages and PDFs.
- Combining structural signals with simple heuristics.

Hands-on: parse an HTML page and produce structure-aware chunks preserving headings and table semantics.
