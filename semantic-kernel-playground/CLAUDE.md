# project description

This is a simple project where I'm experimenting with Semantic Kernel. You do not need to create full structured project, usually all the code in in the program.cs file while all other classes (DTO, etc) are in separate files.

The code is for a course, so I need extensive comment, comments will be made with markdown syntax if possible.

The purpose is to quickly experiment then move all the code in a .dib file, a C# polyglot notebook.

## Important Notes

- The whole new API response are experimental, you need to put the #pragma warning disable OPENAI001 at the beginning of each file using the new API to avoid warnings.
